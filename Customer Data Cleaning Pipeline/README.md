# Customer Data Cleaning Pipeline

This is a simulated SQL case study involving customer data integration and cleaning for a fictional e-commerce SME called TokoBersih.

It is integrates customer data from three different systems and a transaction table into a unified analytical dataset for BI reporting.

## Dataset

The dataset used in this project is provided by NgulikData as part of a SQL course case study.
Tables are:
- pelanggan_legacy
- pelanggan_akuisisi
- pelanggan_modern
- transaksi

## Objectives

- Audit data quality across systems
- Standardize text and phone number formats
- Normalize date formats
- Handle missing values
- Remove duplicate records
- Detect orphan transaction records
- Create a reproducible SQL cleaning pipeline
- Generate a unified customer query with transaction metrics

## Final Output

A unified customer query containing cleaned customer details, transaction count and total sales.
