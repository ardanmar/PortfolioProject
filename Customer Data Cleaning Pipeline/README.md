# Customer Data Cleaning Pipeline

This project is a simulated SQL case study involving customer data integration and cleaning for a fictional e-commerce SME called TokoBersih.

The project integrates customer data from three different systems and a transaction data into a unified and reproducible analytical query for BI reporting.

## Dataset

The dataset used in this project is provided by NgulikData as part of a SQL course case study.
Tables are:
- pelanggan_legacy
- pelanggan_akuisisi
- pelanggan_modern
- transaksi

## Objectives

- Audit data quality across systems
- Standardize text and phone number formats
- Normalize date formats
- Handle missing values
- Remove duplicate records
- Detect orphan transaction records
- Create a reproducible SQL cleaning pipeline
- Generate a unified customer query with transaction metrics

## Final Output

A unified customer-level analytical query containing cleaned customer information, total sales, and transaction count.
