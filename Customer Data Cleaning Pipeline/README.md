# Customer Data Cleaning Pipeline

This project is a simulated SQL case study involving customer data integration and cleaning for a fictional e-commerce SME called TokoBersih.

The project integrates customer and transaction data from three different systems into a unified and reproducible SQL query pipeline for BI reporting and analysis.

## Dataset

The dataset used in this project was provided by NgulikData as part of a SQL course case study.
The tables include:
- pelanggan_legacy
- pelanggan_akuisisi
- pelanggan_modern
- transaksi

## Objectives

- Audit data quality across multiple systems
- Standardize text and phone number formats
- Normalize date formats
- Handle missing values
- Remove duplicate records
- Detect orphan transaction records
- Create a reproducible SQL cleaning pipeline
- Generate a unified customer-level analytical query with transaction metrics

## Final Output

A unified customer-level analytical query containing cleaned customer information, transaction count, and total sales metrics.
